# 2. Motivation

- 기존의 시각 모델들은 각자 정해진 한 분야(분류, 탐지, 분할 등)만 수행하고 언어는 단지 이미지를 설명하는 용도로만 쓰였음
  - 저자들은 언어로 모델에게 다양한 분야를 지시하고 행동을 제어하는 범용 인터페이스로 활용하고 싶어함

- 이미지-텍스트 쌍 데이터는 많지만, AI가 지시를 따르게 훈련할 수 있는 멀티모달 명령어 데이터는 부족함
  - 인간이 일일이 직접 만들기는 비용이 많이 들어서 강력한 언어 모델인 GPT-4를 사용해서 만들자

- NLP 분야에서 모델을 지시 사항에 맞게 조정하여 성능을 높이는 기법이 큰 성공을 거두었음
  - 이 방식을 멀티모달 분야에도 적용해보자!
    - LLM에 시각 인코더(CLIP)를 붙인 뒤, GPT-4로 만든 고품질 멀티모달 지시 데이터로 튜닝하면 범용적인 시각 어시스턴트를 만들 수 있지 않을까?

# 3. Core Idea

- CLIP ViT의 패치별 특징 벡터들을 선형 투영 + 질문 텍스트 임베딩을 Vicuna에 넣어서 답변을 얻음
  - Vicuna: LLaMA(언어 모델)를 사람과의 대화 데이터로 추가 학습해, 질문이나 지시에 응답하도록 만든 모델
    - Vicuna 자체는 언어 모델이지만, LLaVA에서 이미지 정보도 활용해서 답하도록 만드는 것
  - CLIP의 텍스트 인코더는 안씀

- 이미지에 대한 질문과 답변을 GPT-4로 생성 후 LLaVA가 이미지와 질문을 보고 답변을 정답으로 삼아 학습
  - GPT-4에 이미지를 직접 넣는건 아니고, 이미지의 캡션, 객체 이름과 바운딩 박스 좌표를 넣어서 질문과 답변을 생성함
    - 객체 이름과 바운딩 박스 좌표: 어떤 물체가 어디에 있는지 나타내는 정보
    - **GPT-4 입력: “사람이 자전거를 타고 있다”라는 캡션과 객체 위치 정보**
    - **GPT-4 생성: 질문 “사람은 무엇을 타고 있나요?” / 답변 “자전거를 타고 있습니다.”**
    ![alt text](image.png)

- 학습 방식
  - Stage 1: 이미지 선형 투영층만 학습 — CLIP과 Vicuna는 고정
    - 이미지와 질문의 정렬에 집중
  - Stage 2: 이미지 선형 투영층 + Vicuna를 미세조정(fine-tuning) — CLIP은 계속 고정
    - Vicuna는 원래 텍스트만 다루는 모델인데 이미지 정보도 활용해서 답변하는 모델로 바꾸는 과정

# 5. Implementation

- 실제 데이터가 아닌 랜덤값을 입력으로 넣어 Training 순전파 확인
- 의미 있는 데이터가 아니므로 추론 코드는 작성하지 않았음
- 학습 시에는 `질문 + 이미지 패치 + 답변`을 붙여서 입력으로 넣음
- 추론 시에는 `질문 + 이미지 패치`를 붙여서 입력으로 넣음
  - `질문 + 이미지 패치 + 예측단어1`를 다시 입력으로 넣음
    - `질문 + 이미지 패치 + 예측단어1 + 예측단어2`를 다시 입력으로 넣음
      - 이렇게 <EOS> 토큰이 나올 때까지 반복됨
- 사전 학습된 CLIP, Vicuna 모델을 로드 한 후 LLaVA 클래스에서 처리
- Vicuna 모델은 크기 때문에 메모리를 절약하기 위해 float16을 사용함
- stage1, stage2
  - stage1은 `CLIP.requires_grad_(False)`, `Vicunarequires_grad_(False)`로 기울기를 동결 시키고 `이미지 투영층(self.proj)`만 학습시키면 됨
  - stage2는 `CLIP.requires_grad_(False)`, `Vicunarequires_grad_(True)`로 `이미지 투영층(self.proj)`과 Vicuna를 같이 학습시키면 됨
  - 본 구현에서는 순전파만 검증했으므로 고려하지 않아도 됨

# 6. Insights

- 세부 인식 분야와 객체 간 관계를 잘못 이해할 수 있음
  - 냉장고 안의 있는 딸기와 요거트를 딸기맛 요거트로 결합
  - 냉장고 안 사진에서 음식들의 브랜드까지 인식하려면 고해상도 세부 인식 능력이 필요
  - 라멘 가게 이름 인식에는 지식 + 다국어 이해가 필요

- Xsystem-message
  - 모델이 답변을 생성할 때 참고할 지침
    - 페르소나 정의: 모델이 어떤 존재로써 답변해야 하는지 정체성을 부여(예: "너는 mma 코치이다", "너는 ML 엔지니어다" 등)
    - 답변 스타일 및 규칙 설정: 답변의 톤, 형식, 혹은 대화 시 지켜야 할 제약 사항(예: "모르는 질문에는 답변하지 마라", "이러한 형식으로 답변하라" 등)을 고정적인 맥락으로 제공

  - 설계를 바꿨을 때의 성능 차이표
  - 기준 모델 -> 90.92
  - Before last와 Last: CLIP의 어느 층에서 특징을 가져오느냐

      - 마지막 레이어를 거친 특징은 Pooling 때문에 정보가 요약되서 세부적인걸 못 잡는 것 같음
  - Predict answer first: 정답과 설명의 생성 순서를 바꿈
    - 이유 먼저: “이 물체는 나무 재질이므로 … 정답은 A입니다.”
    - 정답 먼저: “정답은 A입니다. 이유는 …”
    - 정답 먼저 생성한 설정 -> 89.77(-1.15)
  - Training from scratch: Stage 1을 건너뜀 -> 이미지 선형 투영층만 학습 — CLIP과 Vicuna는 고정
    - 85.81(-5.11)로 성능에 가장 큰 영향을 미침
  - 7B model size: Vicuna를 작은 모델로 바꿈
    - 13B와 7B는 각각 약 130억 개, 70억 개의 파라미터 수를 뜻함
    - 7B -> 89.84(-1.08)
